# 스펙 — 계정과 프로필

**작성일**: 2026-09-02
**상태**: 현행 — 계정·프로필 요구사항의 원천
**관련 문서**: [decisions/account-deletion.md](../decisions/account-deletion.md) · [decisions/ontology-personalization.md](../decisions/ontology-personalization.md) · [apps/mobile/docs/features/authentication.md](../../apps/mobile/docs/features/authentication.md) · 표기 규칙은 [README.md](README.md)

## 가입과 로그인

- **ACC-1** `구현됨` — 사용자는 이메일/비밀번호 또는 Google 계정으로 가입·로그인할 수 있다.
  이메일 가입은 확인 메일을 거쳐야 완료된다. Apple 로그인은 `보류` — iOS 출시 전에 판단한다(backlog A-4 "iOS 출시 전").
- **ACC-2** `구현됨` — 비밀번호를 잊은 사용자는 이메일 링크로 재설정할 수 있다. 재설정 링크로
  들어온 세션은 새 비밀번호를 저장하기 전까지 앱의 다른 기능에 접근할 수 없다.
- **ACC-3** `구현됨` — 서버 프로필은 첫 로그인 시 자동으로 만들어진다. 사용자가 가입 후
  별도 등록 절차를 밟지 않는다.
- **ACC-4** `구현됨` — 로그인 세션은 앱을 다시 열어도 유지된다. 로그아웃은 사용자가 명시적으로
  수행한다.

## 프로필

- **ACC-5** `구현됨` — 사용자는 **닉네임**을 고칠 수 있다: 나 탭의 이름을 누르면 바꾸는 시트가 열리고
  (1~50자, 앞뒤 공백 없이), 저장한 이름이 나 탭에 보인다. 정한 적이 없으면 로그인 계정의 이름을 보인다. 서버(`PATCH /auth/me`)는
  아바타도 받지만 앱에서 고치지 않는다(2026-10-12 오너 결정):
  - **아바타** — 보여 줄 곳이 없다(나 탭은 이름의 첫 글자를 그리고, 남에게 보이는 화면(피드)은 두지 않는다). 올릴 서버 경로도 없다.
    보여 줄 곳이 생기면 그때 정한다.
  - **관심사** — 사용자는 나 탭에서 **관심사를 고르고 바꿀 수 있다.** 고를 수 있는 것은 서버의 개념 사전에 있는 주제(카페 · 여행 등)이고
    자유 입력은 받지 않는다. 고른 관심사는 사용자 취향의 출발점이 되어 템플릿 순서 · 추천 · AI 편집 초안에 반영된다(PRF-1 · PRF-3).
    관심사를 하나도 고르지 않아도 모든 기능이 동작한다(2026-10-13 오너 결정 — 근거는
    [decisions/ontology-personalization.md](../decisions/ontology-personalization.md)).
    - 나 탭의 `관심사` 행은 고른 관심사를 읽어 준다(이름 둘까지, 나머지는 `외 N개` — `카페 · 여행 외 2개`, 없으면 `고르지 않음`). 누르면
      관심사 화면이 열린다.
    - 관심사 화면은 주제를 모두 보이고(서버가 준 순서), 하나를 누르면 **바로** 고르거나 해제한다 — 따로 저장 버튼이 없다. 위에 고른 수
      (`N개 골랐어요` · `고른 관심사가 없어요`)를 보인다. 저장하지 못하면 고르기 전으로 돌아가고 `관심사를 저장하지 못했어요. 다시 시도해
      주세요.` 를, 주제를 불러오지 못하면 `관심사를 불러오지 못했어요` 와 `다시 시도` 를 보인다.
    - 서버는 사전의 주제만 받는다 — 아니면 거절한다(400 `UNKNOWN_INTEREST`). 예전 빌드가 저장한 자유 문자열은 보이지 않는다.
    - 관심사는 계정의 것이라 다른 기기에서도 같다.
- **ACC-6** `구현됨` — 스냅·무비 라이브러리는 로그인 계정별로 격리된다. 기기에서 계정을
  전환하면 이전 계정의 데이터가 보이지 않는다.

## 계정 삭제와 복구

정책 배경: [decisions/account-deletion.md](../decisions/account-deletion.md)

- **ACC-7** `구현됨` — 계정 삭제는 즉시 파기가 아니라 **30일 유예**를 거친다. 삭제를 요청하는
  화면은 삭제의 결과(무엇이 사라지는지, 언제 사라지는지)를 먼저 보여준다.
- **ACC-8** `구현됨` — 삭제 요청 즉시: SNS 연동과 푸시 토큰이 삭제되고, 진행 중인 무비 생성은
  취소되며 예약 크레딧은 환급된다.
- **ACC-9** `구현됨` — 유예 기간 중 로그인한 계정은 **복구 화면만** 접근할 수 있다. 복구하거나
  로그아웃하는 것 외의 기능은 쓸 수 없고, 남은 유예 기간이 표시된다.
- **ACC-10** `구현됨` — 유예 기간 내 복구하면 계정과 크레딧 잔액이 그대로 돌아온다.
  SNS 연동과 푸시 토큰은 삭제 시점에 이미 정리됐으므로 재등록해야 한다.
- **ACC-11** `구현됨` — 유예 기간이 지나면 배치가 서버의 모든 데이터(스토리지 원본 포함)를
  영구 삭제한다. 삭제된 계정이 기기에 남긴 로컬 데이터는 유예 만료 후 앱이 수거한다.
