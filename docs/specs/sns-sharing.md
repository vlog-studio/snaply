# 스펙 — SNS 연동과 업로드

**작성일**: 2026-09-02
**상태**: 현행 — SNS 공유 요구사항의 원천
**관련 문서**: [sns-setup.md](../sns-setup.md) · [api-spec.md](../api-spec.md) §SNS 연동 · 표기 규칙은 [README.md](README.md)

## 연동

- **SNS-1** `부분`(빠진 것: 틱톡의 앱 연동 진입점 — SNS-8, backlog C-3) — 사용자는 인스타그램·틱톡
  계정을 연동하고 해제할 수 있다. 연동은 플랫폼의 공식 OAuth 로만 하며, 성공·실패 모두 앱
  딥링크로 복귀한다 — 사용자가 브라우저의 에러 페이지에 갇히지 않는다.
- **SNS-2** `구현됨` — 인스타그램은 **프로페셔널(비즈니스/크리에이터) 계정만** 연동할 수
  있다. 개인 계정은 연동을 거부하고 사유를 안내한다(플랫폼 제약).
- **SNS-3** `구현됨` — 연동 토큰은 암호화해 저장하고 평문으로 남기지 않는다. 만료가 임박한
  토큰은 자동 갱신하며, 이미 만료됐으면 재연동을 안내한다.

- **SNS-9** `구현됨` — 사용자가 **Instagram 설정에서 Snaply 를 제거하거나 데이터 삭제를 요청하면** 서버가 Meta 의 서명된 요청을 받아
  그 계정의 Instagram 연동(토큰 · 계정 ID · 사용자명)과 게시 이력에 남은 Instagram 값(게시물 ID · 플랫폼이 준 실패 사유)을 지운다.
  **Snaply 계정 · 스냅 · 무비는 지우지 않는다**(2026-10-11 결정 — Meta 가 요구하는 범위는 Meta 에서 받은 데이터다). 데이터 삭제 요청에는
  상태 확인 주소와 확인 코드를 돌려주며, 그 주소는 언제 무엇을 지웠고 계정은 남았다는 것을 보여 준다. 게시 이력 자체(언제 어떤 무비를
  올렸는지)는 Snaply 의 기록이라 남는다. 앱에서 연동을 **해제하거나 다른 계정으로 다시 연결하면** 그때까지 게시 이력에 남은 그 플랫폼의
  값도 지운다 — 남는 값은 늘 지금 연결된 계정의 것이라, Meta 의 요청은 정확히 그 계정의 값만 지운다. 연결할 때 Instagram 의 프로페셔널 계정
  ID 를 얻지 못하면(프로필 조회를 한 번 더 해도) 연동하지 않는다 — 그 ID 가 없으면 Meta 의 요청과 맞출 수 없다.
  발급된 지 하루가 넘은 요청은 받지 않는다 — 한 번 받은 요청을 누가 다시 보내 다시 연결한 계정을 끊지 못하게(2026-10-15 결정).

## 업로드

- **SNS-4** `구현됨` — **생성이 완료된 무비만** 업로드할 수 있다. 업로드 결과(성공·실패·
  진행 중)와 실패 사유는 이력으로 남는다.
- **SNS-5** `구현됨` — 인스타그램 업로드는 릴스로 게시된다. 게시 완료까지 서버가 확인을
  기다리므로 응답이 수십 초 걸릴 수 있다. 실게시까지 end-to-end 검증 완료.
- **SNS-6** `부분`(빠진 것: 직접 게시 — 플랫폼 심사 대기, backlog C-3. 받은함에 실제로 도착하는지도 아직 보지 못했다 — backlog C-2) —
  틱톡 업로드는 지금 **받은함 방식**이다: 업로드 후 사용자가 틱톡 앱에서 마무리해야 게시되며, 앱은 그 안내를 표시해야 한다.
  플랫폼 심사를 통과하면 직접 게시로 전환된다.
- **SNS-7** `구현됨` — 업로드가 오래 걸리는 플랫폼 사정(틱톡 게시 지연)은 실패로 단정하지
  않고 "업로드 중"으로 표시한다.
- **SNS-8** `구현됨`(Instagram 앱으로 넘기기는 실기기 미검증 — backlog F. 틱톡은 `준비 중`) — 진입점은 둘이다(2026-10-11 결정). **연동은 나 탭의 소셜 연결 화면**에서
  하고(연결 · 해제 · 다시 연결), **게시는 완성 무비의 감상 화면**(공유 옆과 ⋯ 메뉴)에서 한다. 게시는 확인 시트에서 계정과 설명(선택,
  최대 2200자)을 보고 누르며, 그 시트가 **게시하면 이 앱에서 무비가 정리된다**(MOV-17)는 것을 미리 알린다 — 정리는 게시가 성공했을
  때만 일어나고 실패하면 무비는 그대로다. 연동이 만료됐거나 만료 시각을 모르면 다시 연결을 먼저 안내한다. 틱톡은 게시가 미디어 호스트
  검증에 막혀 있어(backlog C-3) 연결 버튼 없이 `준비 중` 으로 둔다. 메타 앱이 개발 모드인 동안은 **앱 역할에 테스터로 넣은 프로페셔널
  계정만** 연동되므로, 테스터 등록과 계정 유형 안내는 앱 밖에서 한다(공모전 운영 전제) — 등록되지 않은 계정의 실패를 앱은 일반 실패로
  알린다.
  그래서 게시 시트는 연결 여부와 상관없이 **"Instagram 앱에서 올리기"** 도 준다 — 무비를 기기 앨범에 저장하고 Instagram 앱을 열어, 사용자가
  Instagram 에서 직접 올린다. 검수 · 테스터 등록 · 프로페셔널 계정이 필요 없고, 앱은 실제로 올렸는지 모르므로 무비를 끝내지 않고 정리를 권한다
  (2026-10-12, [decisions/instagram-app-handoff.md](../decisions/instagram-app-handoff.md)).
